# ros2-sign-recognition #

This is a ROS2 project for the Cognitive Robotics Laboratory course of the Mechatronics Engineering MSc of the Budapest University of Technology and Economics created by József Ferenczy, Mór Sas, Máté Horváth and Barnabás Szabó.

The task is to simulate a racecar with Ackermann-steering in gazebo, which drives around a racetrack autonomously.
The task is to simulate a robot with autonomous driving with additional capabilities of sign or pedestrian recognition.
